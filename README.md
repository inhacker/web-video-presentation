# web-video-presentation

把文章 / 口播稿做成 16:9 可录屏的网页视频演示。

本项目在 `.claude/skills/web-video-presentation/` 中包含
[ConardLi/garden-skills](https://github.com/ConardLi/garden-skills) 的
`web-video-presentation` skill（commit `aaf9a82`，MIT License，见该目录下的 `LICENSE`）。

## 使用

在本目录打开 Claude Code，把文章或口播稿发给它，说"做成网页视频演示"即可。

查看可用主题：

```bash
bash .claude/skills/web-video-presentation/scripts/scaffold.sh --list-themes
```
